## Robots.txt Recommendations

```
User-agent: *
Allow: /

Sitemap: https://swaply.io/sitemap.xml
```

- Allow all crawlers full access to public pages
- Block authenticated routes if needed: `Disallow: /api/`
- Ensure the sitemap is submitted to Google Search Console and Bing Webmaster Tools
- Consider a separate `Disallow` for `/chat` and `/profile` to keep private user content out of search indexes:

```
User-agent: *
Allow: /
Disallow: /chat
Disallow: /profile
Disallow: /api/

Sitemap: https://swaply.io/sitemap.xml
```

## Canonical URL Format

All pages should use locale-prefixed canonical URLs following this pattern:

```
https://swaply.io/[locale]/[page]
```

**Examples:**
- `https://swaply.io/en/objects`
- `https://swaply.io/ro/about`
- `https://swaply.io/fr/pricing`
- `https://swaply.io/de/blog`

**Rules:**
- Every page must have exactly one canonical URL specified via `<link rel="canonical">`
- Use `hreflang` tags to indicate alternate language versions of each page
- The default locale (`en`) should also be explicitly included in `hreflang` annotations
- Trailing slashes should be consistent — pick one convention and enforce it site-wide (recommended: no trailing slash)
