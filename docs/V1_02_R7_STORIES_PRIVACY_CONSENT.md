## Post-application defect found

The verification smoke proved that the original exact-address expression used `\b`, which PostgreSQL POSIX regular expressions do not interpret as the intended word boundary. As a result:

```text
Strada Exemplu 12
```

was not rejected, while email addresses, phone-like strings and coordinate pairs were correctly rejected.

A second issue was identified in the same review: after consent withdrawal, re-publishing the same immutable revision used `ON CONFLICT DO NOTHING`, which could leave the existing snapshot hidden while marking the Story published.

## Forward-only correction

Both issues are corrected by the new registered migration:

```text
supabase/migrations/
20260730211500_v1_02_r7_1_story_privacy_filter_and_republish_fix.sql
```

The correction:

1. uses explicit POSIX-compatible address boundaries;
2. restores the current immutable publication snapshot through `ON CONFLICT ... DO UPDATE`;
3. preserves the snapshot primary key and never deletes publication history;
4. preserves anonymous denial and authenticated participant publication authority.
