## R7.1 correction and verification

R7.1 corrected two issues discovered by post-application verification:

1. the original exact-address expression used `\b`, which PostgreSQL POSIX regular expressions did not interpret as the intended word boundary;
2. re-publishing an existing hidden snapshot for the same immutable revision could leave it hidden because the original function used `ON CONFLICT DO NOTHING`.

The Production smoke now confirms:

```text
safe normal content: accepted
email address: rejected
phone-like string: rejected
coordinate pair: rejected
Romanian exact address: rejected
English exact address: rejected
```

The installed publication function contains:

```text
ON CONFLICT (story_id, revision) DO UPDATE
is_visible = true
hidden_at = null
```

This restores the current immutable snapshot on a valid re-publication without deleting publication history.
