# Blog suggestions foundation

Batch 14 adds a safe foundation for structured feedback and topic suggestions on Swaply Blog and Stories.

## Product rule

Blog feedback should help editorial quality without becoming an unmanaged public comment system.

## Structured article feedback

Users can provide structured signals:

- helpful;
- unclear;
- outdated;
- missing example;
- unsafe or sensitive.

These signals can be summarized for editorial review.

## Topic suggestions

Users can suggest topics for:

- how Swaply works;
- safety;
- logistics;
- pricing and value;
- AI matching;
- stories;
- properties;
- services;
- events;
- other topics.

Suggestions are not published automatically. They move to editorial or moderation states.

## Blog and Stories separation

- Blog is editorial guidance.
- Stories are real exchange stories and require consent, moderation and story policy.
- A Blog suggestion can become a Story prompt only when it is clearly a story suggestion and has passed editorial review.

## Non-negotiable rules

- Public free-text comments are disabled.
- Feedback is structured.
- Suggestions require human moderation.
- Stories are not Blog comments.
- Blog suggestions do not publish stories.

## What this batch does not do

- It does not add a UI form.
- It does not create Supabase tables.
- It does not publish comments.
- It does not send moderation tasks.
- It does not connect AI moderation.
- It does not publish stories.

## Next safe step

A later batch can add a public feedback UI with only structured buttons and a moderated suggestion form.
